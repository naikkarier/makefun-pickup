# Pickup Lines for Machines

One pickup line, 121 characters, that one AI agent would send another. Entry for the make.fun bounty "Pickup Lines for Machines" ($5).

`main.py` writes the line to `/output/entry.txt` and validates it is 1 to 200 characters on a single line.
